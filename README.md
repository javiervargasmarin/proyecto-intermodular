# Implantación y gestión de la infraestructura informática de una PYME

Este proyecto consiste en el diseño, implantación y documentación de la infraestructura tecnológica completa de una pequeña empresa ficticia, desarrollada como trabajo en el módulo de informática.

El objetivo principal es integrar y aplicar conocimientos de distintas áreas como hardware, sistemas operativos, redes, seguridad, servicios en red y desarrollo web, creando una infraestructura funcional, documentada y coherente.
