Módulo · Sistemas Operativos en Red

Ventoy, Dominio Active Directory y GPO

3.1 Ventoy — Gestión de ISOs

Ventoy permite arrancar múltiples imágenes ISO desde un único pendrive (o archivo VDI en VirtualBox). En GameClass se utiliza para centralizar y desplegar los sistemas operativos sin montaje/desmontaje manual de ISOs.

Requisitos del Pendrive Capacidad mínima 16 GB (recomendado 32 GB+) · USB 3.0 · Cualquier sistema de archivos previo (NTFS, exFAT, FAT32)

ISOs utilizadas en el proyecto

ISOFunción en GameClass
Ubuntu ServerServidor principal: controlador de dominio Active Directory (Samba4), DHCP, DNS, Apache
Windows 10Cliente Windows, unión al dominio gameclass.local, prueba de GPO
Debian 12 NetinstCliente Linux, integración con dominio via Winbind/Kerberos, pruebas de conectividad

3.2 Instalación del Dominio en Ubuntu (Samba AD)

Ubuntu actúa como controlador de dominio Active Directory mediante Samba4. El dominio creado es GAMECLASS.LOCAL con controlador dc1.gameclass.local (IP: 192.168.0.2).

sudo apt install samba krb5-user winbind smbclient dnsutils
# Detener servicios clásicos de Samba
sudo systemctl stop smbd nmbd winbind
sudo systemctl disable smbd nmbd winbind
# Crear el dominio Active Directory
sudo samba-tool domain provision --use-rfc2307 --interactive
#  Realm: GAMECLASS.LOCAL
#  Domain: GAMECLASS
#  Role: dc
#  DNS forwarder: 192.168.0.1

Verificación del dominio

sudo samba-tool domain level show
# Forest function level: (Windows) 2008 R2
# Domain function level: (Windows) 2008 R2

host -t SRV _ldap._tcp.gameclass.local
host dc1.gameclass.local
# dc1.gameclass.local has address 192.168.0.2

3.3 Unión al dominio: Debian

sudo apt install samba winbind libnss-winbind libpam-winbind krb5-user -y
# Reino Kerberos: GAMECLASS.LOCAL
# KDC: dc1.gameclass.local
sudo systemctl restart smb nmbd winbind
sudo net ads join -U administrator
# → Joined 'DEBIANPYME' to dns domain 'gameclass.local'
Verificación Kerberos en Debian kinit dev1 → ticket válido · klist → Default principal: dev1@GAMECLASS.LOCAL

3.4 Unión al dominio: Windows 10

  1. Ejecutar sysdm.cpl → Nombre del equipo → Cambiar
  2. Seleccionar "Dominio" e introducir gameclass.local
  3. Autenticarse con credenciales del administrador del dominio
  4. Confirmación: "Welcome to the gameclass.local domain"

4.3 DNS — Samba Active Directory

El servidor DNS está integrado en Samba AD. Se deshabilitó systemd-resolved para evitar conflictos. Registros gestionados:

nslookup gameclass.local       # desde cliente Windows

5.2 Copias de Seguridad

Script automatizado en /usr/local/bin/backup.sh, ejecutado diariamente a las 02:00 vía cron:

#!/bin/bash
FECHA=$(date +%Y%m%d)
DESTINO=/backup
mkdir -p $DESTINO
tar -czf $DESTINO/configs_$FECHA.tar.gz \
  /etc/postfix /etc/dovecot /etc/dhcp \
  /etc/samba /etc/netplan
echo "Backup completado: $FECHA"

Restauración

sudo tar -xzf /backup/configs_FECHA.tar.gz -C /

5.3 Antivirus — ClamAV

sudo apt install clamav clamav-daemon -y
sudo freshclam                              # Actualizar base de datos
sudo clamscan -r /home --infected           # Escaneo manual
# Escaneo semanal automatizado (cron):
0 3 * * 0 clamscan -r /home --infected >> /var/log/clamav_scan.log

5.5 Medidas de Seguridad Lógica

SSH

  • Acceso root deshabilitado: PermitRootLogin no
  • Máximo 3 intentos: MaxAuthTries 3

Samba AD

  • Políticas de contraseñas activadas
  • Kerberos para autenticación segura
  • LDAP para gestión centralizada de usuarios

Correo (Postfix/Dovecot)

  • Autenticación obligatoria para envío
  • Buzones individuales por usuario
  • Autenticación contra Samba AD via PAM + Winbind

Pruebas de Vulnerabilidad

  • Escaneo con nmap -sV 192.168.0.2
  • Puertos abiertos: solo servicios legítimos
  • Sin puertos innecesarios expuestos

GAMECLASS Web App — Firebase + Tailwind CSS

GAMECLASS es el sitio web corporativo del estudio, construido como una aplicación web estática multi-página (MPA) con Tailwind CSS y Firebase como backend (autenticación + Firestore en tiempo real).

├── clientes.html     → Área privada (Firebase Auth + compras)

├── styles.css        → Tema neo-brutalista, modo oscuro
